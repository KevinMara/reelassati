# Editor source audit — 15 September 2026

## Scope and evidence

The OpenCut and OpenCut Classic repositories were downloaded for source inspection. Their tracked source trees were searched across timeline, commands, rendering, animation, subtitles, transcription, graphics and effects; the implementation files below were read. This is an architectural and selected-file audit, not a claim that every line of either repository was reviewed.

- [OpenCut](https://github.com/OpenCut-app/OpenCut), snapshot `400f097becba5db0fbc305d5a65348cb81c20356`.
- [OpenCut Classic](https://github.com/opencut-app/opencut-classic), snapshot `cf5e79e919144200294fb9fed22a222592a0aeea`.
- Both LICENSE files grant MIT reuse, including commercial modification and distribution, provided the copyright and permission notice accompany copies or substantial portions. This permission applies to that software; it is not a blanket license for unrelated downloadable audio, fonts, templates or examples.

OpenCut's current README says its main repository is being rewritten, with an Editor API, plugins, Rust core, MCP and headless automation in its roadmap. It explicitly points to Classic as the current version. The rewrite's web UI and desktop shell are not a complete drop-in editing engine.

## OpenCut Classic findings and implementation decisions

| Area                          | Files inspected                                                          | Finding and decision                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Split, retime and undo        | `commands/timeline/element/split-elements.ts`, command tree              | A split preserves source spans and splits animation data. Source boundaries should be rounded once and the complementary span derived, preventing gaps from separate rounding. Preserve this invariant in the existing editor; a rewrite of all state managers is unnecessary.                                                                                                                |
| Placement and numbered layers | `timeline/placement/main-track.ts`, placement and controller tree        | Main-track placement can force the first clip to time zero. That conflicts with the requested drop-at-cursor behavior, so it is intentionally not adopted. Multiple explicit visual/audio lanes are the appropriate model here.                                                                                                                                                               |
| Keyboard input                | `actions/keybindings-store.ts`, keybinding migrations and commands       | Shortcuts are centralized and suppress editing commands while typing or interacting with dialogs. Adopt these interaction rules with the current editor's own state and history.                                                                                                                                                                                                              |
| Subtitles                     | `subtitles/parse.ts`, `srt.ts`, `build-subtitle-text-element.ts`         | Classic imports SRT and ASS and creates editable text elements with placement and typography. REELASSATI now has original SRT/WebVTT parsing and SRT export, with exact supplied timing, plus a shared caption style contract for preview and MP4 output. ASS import is not implemented.                                                                                                      |
| Automatic caption timing      | `transcription/caption.ts`, `caption-defaults.ts`, transcription service | Classic defaults to three words per caption and estimates chunk timings from segment duration, with a minimum duration. Do not present such estimates as observed word timing. Current captions retain supplied/transcribed cue timings. Word-level karaoke needs real word timestamps before it can be advertised as synchronized.                                                           |
| Transcription runtime         | `services/transcription/service.ts`, worker/model tree                   | Classic uses a dedicated browser worker with model initialization and progress reporting. Self-hosting a transcription model is a separate performance/download decision, not something provided automatically by copying its panel.                                                                                                                                                          |
| Effects                       | `effects/registry.ts`, `definitions/blur.ts`, definition tree            | A registry separates parameters from render passes. At this snapshot, Gaussian blur is the registered effect definition found in the effects directory; there is no complete hidden pack of transitions or After Effects plugins to copy. REELASSATI's current preset catalog exposes the color and fade operations its exporter actually supports.                                           |
| Graphics and animation        | graphics definitions, animation and renderer trees                       | Classic includes rectangle/ellipse/polygon/star primitives, keyframes, interpolation, masks, GPU/canvas renderers and export integration. These are useful architectural references; copying a renderer node without its state, font and export paths would yield incomplete controls. REELASSATI uses its own deterministic graphic-frame representation for both preview and ASS rendering. |

No OpenCut source implementation was copied into the preset or subtitle helpers in this change. Those are original implementations adapted to REELASSATI's existing contracts. If code is copied in a future change, preserve the relevant MIT notice with the copied files and in distributed third-party notices.

## Ready-to-use presets delivered

- **12 caption styles:** Classic, Bold statement, Yellow focus, Editorial, Minimal, Black label, White label, Violet label, Red label, Cyan focus, Top line and Warm editorial. Each has a concrete font size, safe margin, color, outline/background, capitalization and line wrapping. The same definition drives the preview and exported subtitles.
- **19 graphic presets:** title, callout, lower-third, quote, chapter, CTA, counter, countdown, pointer, focus frame, editable motion-path variants and three dimensional graphic presets. These create editable graphic settings, not flattened stock footage. The dimensional presets depend on the separate shared 3D projection implementation in this release.
- **8 color looks and 5 fade settings:** use the existing brightness, contrast, saturation, fade-in and fade-out controls. These are named as looks/fades, not advertised as complex crossfades, tracking or generative effects.
- **SRT/WebVTT import and SRT download:** multiline and Unicode text, millisecond timing, invalid-cue reporting and bounds checking. Replacing existing captions requires an in-product confirmation. Import does not spend AI credits.

Preset definitions are original, and the existing bundled editor font is used. `contracts/caption-font-metrics.json` contains glyph advances extracted from `public/fonts/DejaVuSans.ttf`, covered by the bundled DejaVu license, so wide characters wrap inside the safe area in both preview and export. Preset use does not call paid AI providers. Native FFmpeg verification checks real rasterized caption placement and selected colors; other tests check timestamp preservation, cue clipping, Unicode and renderer contract round trips.

## After Effects and downloadable libraries

An `.aep` file is an After Effects project, not a self-contained browser effect. Downloading templates does not install Adobe's rendering engine or required plugins. Adobe's [rendering/export documentation](https://helpx.adobe.com/after-effects/desktop/render-and-export/basics-of-rendering-and-exporting/basics-rendering-exporting.html) describes rendering a composition through its render queue into output media. Native `.aep`/`.mogrt` execution is not present in REELASSATI.

Compatible options are original editable graphics implemented in the shared renderer, properly licensed rendered clips with transparency, or a specifically supported animation format with a matching export renderer. Lottie is not a universal converter for After Effects: [its supported-feature matrix](https://lottiefiles.com/supported-features) distinguishes shape/text features and unsupported 3D-layer functionality. A full Lottie import/export path is not implemented in this change.

Downloaded asset packs require permission to redistribute the individual assets inside a shared customer-facing library, not only permission to use them inside a finished video. Popularity and a public download URL do not establish those rights. The separate audio-asset manifest records per-source licensing evidence; assets with unresolved redistribution terms should not be presented as cleared stock.

## Remaining capabilities not established by this audit

Do not claim full OpenCut/After Effects/Agent28 parity, universal social-video ingest, exact reference replication, automated scene tracking, rotoscoping, arbitrary third-party plugins, word-synchronized karaoke, or native After Effects template execution. These require their own complete implementation and functional export verification. The delivered preset catalog is intentionally explicit about what the renderer can execute today.

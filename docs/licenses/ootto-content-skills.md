# Ootto content skill attribution

The structured writing workflow in `contracts/script-writing-pack.ts` is adapted from Ootto's public content skills. REELassati implements its own bounded schema, validation, source-clock separation and persistence; it does not install or execute Ootto's plugin or its agents.
